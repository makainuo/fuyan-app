# 再捞我一下 · ZaiLao

本地优先的医学课程复习工具。名字来自“都快沉了，还觉得自己稳了”——让漏勺再捞一把。

![应用 Logo](fuyan/assets/logo.svg)

- **Windows 桌面版**：[使用说明](fuyan/README.md)，双击 `fuyan/启动再捞我一下.vbs`。
- **课程存档**：一门课包含正文、题库及导航，持续新增课程；无需为每门课重新制作软件外壳。
- **原生 Android 刷题版**：保留在 `app/`，本次 Windows 品牌与启动改动不改变 Android 功能。

Windows 版提供阅读、目录、书签、搜索、刷题、批注及可选 AI 问答。学习数据保存在本机，程序更新与课程内容分离。

源自复研 MedReview 和 shauti-app；保留旧存档格式与数据目录用于兼容。
