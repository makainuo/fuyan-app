# 再捞我一下：名称与图标

应用面向持续增加的医学课程，阅读、检索、刷题、批注和 AI 问答由统一外壳承载，课程以存档加入。

## 名称与语气

名称由「复研 MedReview」改为「再捞我一下」。希望表达学生复习时的幽默和一点嘴硬，而不是学院式命名或单纯卖萌。

探索阶段讨论过「知屿、回响、拾知、脉络」及「捞捞、脑花、过过、咕知」等方向。最终选中「再捞我一下」，保留原「过过」方向的蓝紫小人与荧光绿配色。

## 最终图形

![最终 Logo](../assets/logo.svg)

蓝紫小人半泡在水里，被漏勺从下面托起，脸上仍然很有把握：**都快沉了，还觉得自己稳了。**

- 最终使用漏勺，替代容易引起“挂”联想的悬吊钩子。
- 水铺到圆角图标底部和两侧，不在水外包绿色边框。
- 水位适当降低，小人与漏勺上移并放大，增加错落的水波纹。
- 删除两侧含义不明的黑色动作线。
- 采用 SVG 原稿，保留明确轮廓和有限色彩。

## 文件与生成

- `assets/logo.svg`：唯一图形源文件；`web/brand/logo.svg` 用于应用顶栏、启动页和网页图标。
- `assets/zai-lao-taskbar.ico`：Windows 任务栏图标；`assets/zai-lao.ico` 与 `assets/icon.ico` 为兼容资源。
- ICO 包含 16、20、24、28、32、40、48、64、80、96、128、256 像素，每个尺寸直接从 SVG 渲染。
- 重新生成：安装 Python 的 `resvg-py`，在应用目录执行 `python tools/build_windows_icons.py`。
- 任务栏使用 `ZaiLao.App` 标识，通过窗口属性设置图标资源。图标由 Windows 从磁盘加载，不依赖短命辅助进程拥有的 HICON。

## 原有数据继续可用

本次改的是产品名称和外观，`%APPDATA%/fuyan`、`FUYAN_DATA`、`fuyan/archive@1`、题目 id 及内部接口标识保持兼容。用户的课程、批注、进度和配置不随外观改名迁移。
