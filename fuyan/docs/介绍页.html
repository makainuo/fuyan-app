复研 MedReview01 · 问题
先说问题

复习资料的三件麻烦事

不是不努力，是工具之间接不上：读的是一套，练的是另一套，想回头找又找不到。

01

资料是散的

PDF、课件、网页、学长笔记各在一处。读的时候很顺，合上就忘；想找某个数字，得把四五个文件翻一遍。

02

复习站只能读

排版好看、内容也全，但页面里没有题。看完一章，不知道自己到底会不会，只能再去找题库。

03

刷题 App 换课就重来

题库写死在软件里。想换一门课，要么等作者更新，要么重新导入、重新整理，之前的批注和进度也带不走。

读的时候很顺，做题的时候很慌——中间缺一个把「内容」和「练习」放在一起的东西。

复研 MedReview02 · 做法
我们的做法

把「软件」和「课程」拆开

复研本身不含任何课程内容。它只做一件事：读一种叫「存档」的文件夹。内容、题库、样式都在存档里，软件只负责把它们用起来。

manifest.json标题 · 导航 · 版本
content.html正文 + 原站样式
questions.json题库 · 答案 · 解析
→
存档
一门课的全部内容
→
复研
读 · 刷 · 批注 · 问
换课，不换软件
换一门课只是换一个存档文件夹。软件不用重装，批注和进度按存档分开存。
内容还是原样
正文就是原来的复习站，折叠、翻转、速查表原样保留，不需要重新排版。
存档可以流通
本地导入、链接导入、从 GitHub 下载，或从作者网盘拿。别人做好一门课，导入就能用。
课不是一个标签，
而是一个可以拷走的文件夹。
旧的做法内容在一个地方，练习在另一个地方，批注在第三个地方。每换一门课，三样都要重新来一遍。
复研的做法内容、题库、批注、进度都跟在「存档」里。换课，只是换一个文件夹。

复研 MedReview05 · 批注与 AI
功能 · 批注与 AI

不懂的地方，选中就能问

看不懂的词，选中就有答案；写下来的批注，永远在原文旁边。

① 选中文字，气泡里点「问 DeepSeek」
② 侧栏直接给答案：定义、关键点、易混、易错
三种动作，一步到位写自己的批注、直接问 AI、或在站内搜索这个词。
批注贴着原文高亮常驻原位置，重开软件还在；同一段只留一条。
追问接在后面再问同一段，接着原来的对话往下聊，不新开一条。
对话可以回看记录面板能看到每条对话，关掉软件也在。
你追问
那它和「波状热」怎么区分？
DEEPSEEK
波状热是体温逐渐升高又逐渐下降，像波浪；稽留热是持续高热、24 小时波动不超过 1℃。
选中同一段文字再打开，看到的是原来那条批注的完整对话，追问接在末尾——上下文不断，也不会越堆越多。

复研 MedReview06 · DeepSeek
亮点 · 用你自己的 DeepSeek

AI 不是租来的，是你自己的

复研不代收 AI 费用，也不经过作者服务器。设置一次 API Key，之后每个提问都从你自己的账号走。

设置 → DeepSeek：填 Key、选模型、点「测试连接」
01
创建 Key打开 platform.deepseek.com，登录后创建一个 API Key（sk-…）。
02
粘贴保存回「设置 → DeepSeek」粘贴保存；模型默认 deepseek-flash。
03
测试连接点「测试连接」确认可用，之后选区提问直接走你的账号。
数据不出本机Key 只存这台电脑；请求由软件自己的本地服务转发，网页里拿不到。
按自己的用量付费没有中间商加价，用多少扣多少，也没有“额度用完了”的墙。
模型可选deepseek-flash 快而便宜；需要更强推理可以换更强的模型。
没配也不卡住点 AI 会弹出引导，告诉你三步怎么配，不会静默失败。
为什么不是“扫码登录”？DeepSeek 官方只提供 API Key，没有扫码授权；所谓“扫码就能用、作者统一扣费”，需要作者自建后端账号体系，那是另一套产品。复研选了更简单也更透明的方式：你自己拿 Key，自己付钱，数据只在本地。

复研 MedReview07 · 存档从哪来
存档从哪来

现成的直接用，自己的随时发

LOCAL
本地导入
把存档 zip 拖进软件，或选文件夹导入。自己做课也一样。
LINK
链接导入
粘贴一个 http/https 直链，软件下载后自动导入。
GITHUB
在线存档
作者把存档清单放在 GitHub，软件里点一下就能下载最新版。
QUARK
网盘（作者通道）
作者的夸克网盘目录直接列出，同名新包顶替，旧包自动归档。
存档库：作者发布的存档直接列出，已安装的会标出来
批注、进度、对话都存在本机（%APPDATA%\fuyan），覆盖安装新版本也不会丢；存档包本身不带任何个人数据。

复研 MedReview08 · 上手
上手

三步开始

1
解压，双击启动一个文件夹，双击「启动复研」就有桌面图标；需要本机装 Node.js 18+。第二次打开会直接聚焦已有窗口。
2
导入一门课的存档从「存档库」导入 zip，或从 GitHub 在线存档里挑一份，几秒钟就绪。
3
读、刷、问读的时候选中不懂的词直接问；读完去刷题；错题留着，考前再刷一遍。
内容与软件分离换课不换软件，软件可以一直用下去
复用已有复习站不用重做内容，原排版原交互直接用
本地优先批注、进度、对话不上云，数据自己拿着
轻软件包 165 KB，不装数据库、不常驻后台
适合谁
期末复习的医学生把复习站当教材，做题当自测，不懂就选中问。
想给课程配题库的人已有网页资料，补一份题目就能做成存档。
带课的老师和学长做好一门课发出去，别人导入就能用。
